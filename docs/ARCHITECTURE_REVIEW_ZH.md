## 成熟度改造顺序

1. **补齐证据边界。** 将旧 `attacker_id` 作为历史回放簇使用。在线模拟 AI 已将共享网段和凭据的独立客户端观测分开。继续接入跨协议证据和受审核的关联，验收加入实际 NAT、代理、复用凭据和独立访客反例。
2. **扩展 DWS 发布。** 在现有跨协议文档与目录投影上接入自动模型提案、终端日志、服务节点和运行器就绪状态。让统一发布描述版本和服务清单，继续验证并发、乱序和依赖失效。
3. **分别验收岗位和访客链路。** 员工沿各自服务完成排班任务。访客由模拟日志跟进到新服务，Dashboard 展示流记录、协议事件、交付和使用关联。分别验证新会话、已绑定会话和依赖故障。
4. **补齐生产运维。** 管理端接入多用户鉴权、最小权限和逐操作审计。对事件保留、SQLite 写入压力、归档备份与重启恢复建立负载测试。按目标网络和发布边界验证防火墙、外部入口、脱敏与可回退性。
5. **做对照评估。** 隔离采样比较固定场景、规则适配和 AI 适配，发布同口径的行为跟随率、误报、成本和延迟。实测结果与生产结论分开记录。

## Dashboard 改动

十二个菜单共享导航、响应式布局、表格搜索和分页。告警可按协议和类型筛选。会话页面用中文说明请求、交付与生成依据。「攻击链路」将 Web 交付回执关联到后续入口命中，展示来源会话、DWS 版本、发生时间、撤销状态和实际匹配的流记录。Canary 页面展示凭据标识与响应回执，场景发布页面保留审批和回滚。DWS 页面可查看实体和关系并比较公开版本。「合成数据发布」支持图草稿、审核、发布与撤回。服务页面使用探测状态、单请求延迟样本、模型预算和员工运行记录。态势报告可展示每小时或由实际 Canary 证据触发的记录。证据处置页面记录申请、审核和执行状态。

## 链路证据与生成预算

初始 Canary 由 Web 按场景、会话和诱饵签发。响应发送回执和后续使用观测进入研究账本。在配置的多跳路径上，验证成功的入口签发下一跳凭据，并写入父凭据和父命中记录。Dashboard 只为有发送回执和匹配使用的记录连线。链路证明凭据传递和复用，支持撤销关联。历史的同凭据多入口观测仍可查询。

自动 Web 场景最多 8 个页面、8 个模拟 HTTP 接口、32 条边。每个节点最多 8 条关联边，入边和出边合计。单次在线补丁最多写 4 个页面。SSH、MySQL 和模拟 AI 蜜饵可选一个 DWS 实体和一个已有关系相连的邻居。人工文档目录图最多 8 个节点和 12 条边，每份文档最多关联两个目录，每个目录最多关联四份文档，每个节点至少参与一条关系。发布规划限制一次发布最多启动 1 个独立实例。定向 Canary 最多四跳，并受协议范围、交付回执、到期和撤销检查约束。

## SSH 流证据与双角色处置复验

虚拟环境中用真实 Cowrie 捕获了 SSH 目标连接，生成与该观测匹配的合成 AWS VPC Flow Logs 样本，分别测试重复、错误接口、错误端口、错开时间和同五元组歧义。Dashboard 显示唯一可确认的网络侧匹配。此项复验使用合成流日志，目标 AWS VPC 尚未接入。

运营账号提交、审核账号批准、并发修订冲突、审核驳回、重新打开账本与恢复关联均有测试覆盖。实际撤销后访问测试 Canary 返回 404，既有命中记录仍能查询。浏览器实测了证据展开和审核后链路状态刷新。新增管理路径在访客面返回 404。

## 图发布与四入口复验

后续复验 `deploy/check-v2.sh` 通过 410 项测试、两次逐字节回放及 10,000 条轨迹。对同一合成图分别使用独立 Web、SSH、MySQL 和模拟 AI 票据，四入口读取同一分支内容。普通与旧会话没有读到分支文档或目录。注入 SSH 投影写入故障后，DWS 和终端投影均保留原版本。再次注入队列确认前的中断，重开写入器后复用已提交版本。图撤回后的发放限制和历史快照已验证。

## 生命周期与生成可靠性

到期的协议蜜饵和 Web 自适应分支现在从在线世界移入 SQLite 归档。活跃 Web 会话续期，仍被有效票据引用的版本保留。归档、在线快照和终端投影同事务更新。归档保留原世界版本和事实标识，重新启用同一生成主题可获得新的事实标识。已发布且可用的固定场景保留供回滚。

生成内容对宿主、引擎、版本与访问边界使用结构化声明，发布时从基线重建并核对。结构化事实经过程序验证，普通正文的自然语言含义继续由模型复核。

封闭合成对照在同一个 Web 基线完成。规则组在已知闭集任务中达到与 DeepSeek 相同的命中率，耗时更低。该结果衡量固定任务响应匹配，真实访客行为与长期策略收益需要独立评估。演练记录见 [生命周期和三组对照](PROGRESS_V2.md)。
